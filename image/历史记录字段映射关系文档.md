# 历史记录字段映射关系文档

## 概述

本文档详细说明了前端历史记录数据结构与后端API接口返回值之间的映射关系。历史记录数据主要来源于两个后端接口：
1. **产假计算接口**：`/api/maternity-leave/calculate`
2. **津贴计算接口**：`/api/maternity-allowance/calculate`

## 存储结构

### localStorage存储键名
- **主要键名**：`hr_maternity_history`
- **备用键名**：`allowanceHistory`、`maternityHistoryRecords`

### 数据格式
```typescript
interface HistoryRecord {
  id: string
  employeeName: string
  employeeId: string
  city: string
  cityName: string
  startDate: string
  endDate: string
  totalDays: number
  companyCompensation: number
  employeeCompensation: number
  calculatedAt: string
  recordType: 'allowance' | 'maternity'
  vacationData: VacationCalculation
  allowanceData: { [key: string]: unknown }
  receivedTime?: string
  submissionTime?: string
}
```

## 4. API接口字段映射

### 4.1 产假计算接口响应字段映射

```typescript
// 产假接口响应 → 历史记录映射
ApiCalculateResponse {
  lanId?: string                    → employeeId
  employeeName?: string             → employeeName  
  cityCode?: string                 → city
  cityName?: string                 → cityName
  totalDays?: number                → totalDays
  total?: number                    → totalDays (备用)
  totalAllowanceDays?: number       → vacationData.totalAllowanceDays
  baseDays?: number                 → vacationData.baseDays
  extendedDays?: number             → vacationData.extendedDays
  dystociaDays?: number             → vacationData.dystociaDays
  multiBabyDays?: number            → vacationData.multiBabyDays
  startDate?: string                → startDate
  endDate?: string                  → endDate
  returnToWorkDate?: string         → vacationData.returnToWorkDate
  timeScopeList?: TimeScopeItem[]   → vacationData.timeScopeList
  isFirstTimeBirth?: boolean        → vacationData.isFirstTimeBirth
  breakdown?: {                     → vacationData.breakdown
    baseDays?: number
    additionalDays?: number
    bonusDays?: number
    difficultBirthDays?: number
    multipleBirthDays?: number
  }
}
```

### 4.2 津贴计算接口响应字段映射

```typescript
// 津贴接口响应 → 历史记录映射
MaternityAllowanceResponse {
  lanId: string                     → employeeId
  employeeName: string              → employeeName
  cityCode: string                  → city
  cityName: string                  → cityName
  totalAllowance: number            → allowanceData.totalAllowance
  dailyAllowance: number            → allowanceData.dailyAllowance
  allowanceDays: number             → allowanceData.allowanceDays
  calculationBase: number           → allowanceData.calculationBase
  extraAllowance: number            → allowanceData.extraAllowance
  maternityAllowance: number        → allowanceData.monthlyAverageSalary
  governmentAllowance: number       → allowanceData.governmentSubsidy
  compensationAmount: number        → companyCompensation
  allowanceCompensationDetails: string | string[] → allowanceData.allowanceCompensationDetails
  employeeRefundAmount: string      → employeeCompensation (parseFloat)
  paidMaternityWage: number         → allowanceData.paidMaternityWage
  refundDetails?: string | string[] → allowanceData.refundDetails
}
```

## 5. 数据流转说明

### 5.1 产假计算阶段
1. 用户填写产假计算表单
2. 调用产假计算接口 `/api/maternity-leave/calculate`
3. 接口返回产假计算结果
4. 保存历史记录，`recordType = "maternity"`，`companyCompensation = 0`，`allowanceData = {}`

### 5.2 津贴计算阶段
1. 基于产假计算结果，用户填写津贴计算表单
2. 调用津贴计算接口 `/api/maternity-allowance/calculate`
3. 接口返回津贴计算结果
4. 更新历史记录，`recordType = "allowance"`，填充完整的津贴数据

### 5.3 数据去重逻辑
- 同一工号(`employeeId`)只保留最新记录
- 新记录会替换旧记录
- 记录按时间倒序排列（最新在前）

## 6. 注意事项

### 6.1 数据类型转换
- 金额字段需要使用 `parseFloat()` 转换
- 日期字段统一使用 ISO 8601 格式
- 布尔字段需要明确转换

### 6.2 兼容性处理
- API响应字段可能存在多个别名，需要做兼容处理
- 历史数据可能存在字段缺失，需要提供默认值
- 支持多个localStorage键名的数据合并

### 6.3 特殊城市处理
- 绍兴：支持一孩选项 (`firstChild`, `isFirstTimeBirth`)
- 上海：支持单位申报工资 (`declaredSalary`)
- 特定城市：支持产假提交时间 (`maternitySubmissionDate`)
