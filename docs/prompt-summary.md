# 提示词总结
## 项目初始化
你作为一名java 专家，初始化一个 名为 ms-hr-maternity 的 产假计算系统 项目
该项目主要使用的技术栈如下：
- 核心框架 springboot，并且支持swagger
- 数据库使用pgsql， 数据库连接层使用JPA, 并且使用 flyway 脚本

## 项目架构初始化
你作为一个系统设计专家， 现在有一些系统设计的需求如下，帮我生成系统架构代码，具体的计算逻辑可以不生成
- 系统需要支持14个城市 产假计算 和 津贴计算
- 产假计算 和 津贴计算 需要按照 策略模式 每个城市都要有自己的计算方式
- 14个城市分别是 上海，深圳， 广州， 天津， 绍兴， 厦门， 成都， 苏州， 青岛， 北京， 重庆,珠海， 武汉， 佛山
- 计算产假的策略 放在 leave目录下
- 计算津贴的策略 放在 allowance目录下

## 实现假期服务
你作为一名java 专家，帮我设置 HolidayService, 核心功能如下
- 提供一个 获取公共假日的方法
- 获取公共假日的方法的数据源是从调用第三方获取（https://unpkg.com/holiday-calendar/data/CN/）
- 获取的逻辑是，先存数据库获取，如果数据库没有就调用第三方获取，并且获取完成后存入数据库，如果数据库有就直接返回

## 实现 深圳津贴计算
@ShenzhenAllowanceStrategy.java  中 calculateAllowance 的方法计算逻辑
- 计算生育津贴：产前12个月月均工资 / 30 * 产假天数，四舍五入保留2位小数
- 员工应享受补贴： 是 生育津贴 和 政府发放补贴金额 取最大值
- 计算补差：
  - 如果 政府发放金额 >生育津贴, 则补差为 政府发放金额 - 产假应付工资， 如果 政府发放金额 < 生育津贴, 则 补差为 生育津贴 - 产假应付工资
  - 如果补差是负数 则在 allowanceCompensationDetails 中的 显示 补差金额： 显示计算过程， 计算结果为负，取0， 而且 在MaternityAllowanceResponse 中的compensationAmount显示0
- 返回之中的 allowanceCompensationDetails包含如下：
    - 产假期间发放工资
    - 员工产前12个月月均工资计算补贴金额
    - 政府发放补贴金额
    - 员工应享受补贴
    - 补差金额
