## Excel 制作步骤

### 1. 创建表头
在 Excel 第一行输入上述所有列名（必须完全一致，包括空格）

### 2. 输入测试数据
从第二行开始输入测试用例数据

### 3. 设置单元格格式

#### 日期列（重要！）
选中以下列，设置为日期格式（yyyy-MM-dd）：
- 产假开始时间
- 发放时间
- 提交核定表时间
- 产假结束日期
- 预计返岗日期

**操作步骤：**
1. 选中日期列
2. 右键 → 设置单元格格式
3. 选择"日期"
4. 选择格式：yyyy-MM-dd

#### 数值列
选中所有金额和数值列，设置为数值格式：
- 保留 2 位小数（金额）
- 保留 0 位小数（天数、胎数等整数）

#### 布尔列
以下列可以使用多种格式表示：
- 是否有奖励假：是/否、true/false、1/0
- 是否跨4月调薪：是/否、true/false、1/0
- 是否跨7月社保调整：是/否、true/false、1/0

### 4. 保存文件
- 文件格式：.xlsx（推荐）或 .xls
- 文件名建议：maternity-test-cases-YYYYMMDD.xlsx

## 使用方式

### 使用 Postman
1. 新建 POST 请求
2. URL: `http://localhost:8080/api/batch-test/maternity/run`
3. Body 选择 `form-data`
4. Key: `file`，类型选择 `File`
5. Value: 选择你的 Excel 文件
6. 点击 Send

### 使用 curl
```bash
curl -X POST http://localhost:8080/api/batch-test/maternity/run \
  -F "file=@maternity-test-cases.xlsx"
```

### 使用 Swagger UI
1. 访问 `http://localhost:8080/swagger-ui.html`
2. 找到 "批量测试" 分组
3. 展开 "运行产假津贴批量测试" 接口
4. 点击 "Try it out"
5. 选择文件并执行

## 注意事项

1. **表头必须完全一致**：包括空格、标点符号等
2. **日期格式**：必须设置为日期类型，格式 yyyy-MM-dd
3. **数值精度**：金额建议保留 2 位小数
4. **空值处理**：非必填字段可以留空
5. **文件大小**：建议单个文件不超过 10MB
6. **测试用例数量**：建议单次测试不超过 1000 条

## 常见问题

### Q1: 日期显示为数字怎么办？
**A:** 选中日期列 → 右键 → 设置单元格格式 → 日期 → yyyy-MM-dd

### Q2: 表头名称必须完全一样吗？
**A:** 是的，必须完全一致，包括空格和标点符号

### Q3: 如何表示布尔值？
**A:** 可以使用：是/否、true/false、1/0 任意一种

### Q4: 非必填字段可以留空吗？
**A:** 可以，解析器会安全处理空值

### Q5: 支持多个 Sheet 吗？
**A:** 当前只解析第一个 Sheet

## 扩展开发

如需集成实际的产假和津贴计算服务，请修改 `MaternityBatchTestService.executeMaternityTestCase()` 方法：

```java
private TestCaseResultDTO executeMaternityTestCase(int rowNumber, MaternityTestCaseDTO testCase) {
    // 1. 构建产假计算请求
    MaternityLeaveRequest leaveRequest = MaternityLeaveRequest.builder()
        .cityCode(testCase.getCityCode())
        .deliveryMethod(testCase.getDeliveryMethod())
        .startDate(testCase.getLeaveStartDate())
        .build();
    
    // 2. 调用产假计算服务
    MaternityLeaveResponse leaveResponse = maternityLeaveService.calculateMaternityLeave(leaveRequest);
    
    // 3. 构建津贴计算请求
    MaternityAllowanceRequest allowanceRequest = MaternityAllowanceRequest.builder()
        .leaveDays(leaveResponse.getTotalDays())
        .avgSalary(testCase.getAvgSalaryBefore12Months())
        .build();
    
    // 4. 调用津贴计算服务
    MaternityAllowanceResponse allowanceResponse = maternityAllowanceService.calculateAllowance(allowanceRequest);
    
    // 5. 比较结果并返回
    return compareAndBuildResult(testCase, leaveResponse, allowanceResponse);
}
```
