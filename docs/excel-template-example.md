## 数据类型说明

### 支持的数据类型

1. **字符串（String）**
   - 示例：`SH`, `NORMAL`, `张三`
   - Excel 格式：文本

2. **整数（Integer/Long）**
   - 示例：`158`, `15000`, `1`
   - Excel 格式：数值（无小数）

3. **小数（Double）**
   - 示例：`79000.50`, `3.14`
   - Excel 格式：数值（有小数）

4. **日期（LocalDate）**
   - 示例：`2024-01-15`
   - Excel 格式：日期（格式：yyyy-MM-dd）
   - **重要**：Excel 单元格必须设置为日期格式

5. **布尔值（Boolean）**
   - 示例：`true`, `false`, `是`, `否`, `1`, `0`
   - Excel 格式：文本或布尔值

## Excel 文件制作步骤

### 步骤 1：创建表头
1. 在第一行输入列名
2. 列名要清晰明确，与代码中使用的名称一致
3. 建议使用中文列名，便于理解

### 步骤 2：输入测试数据
1. 从第二行开始输入测试数据
2. 确保数据类型正确
3. 日期列要设置为日期格式

### 步骤 3：设置单元格格式
1. 选中日期列 → 右键 → 设置单元格格式 → 日期 → yyyy-MM-dd
2. 选中数值列 → 右键 → 设置单元格格式 → 数值 → 设置小数位数
3. 文本列保持默认格式

### 步骤 4：保存文件
1. 文件 → 另存为
2. 选择格式：`.xlsx` (推荐) 或 `.xls`
3. 保存到合适的位置

## 常见问题

### Q1: 日期显示为数字怎么办？
**A:** Excel 单元格格式设置为日期类型：
1. 选中日期列
2. 右键 → 设置单元格格式
3. 选择"日期"类别
4. 选择格式：yyyy-MM-dd

### Q2: 数字精度丢失怎么办？
**A:** 对于大数字或需要精确小数的列：
1. 选中该列
2. 右键 → 设置单元格格式
3. 选择"数值"类别
4. 设置合适的小数位数

### Q3: 空值如何处理？
**A:** 
- 留空即可，解析器会返回 `null`
- 代码中使用 `ExcelParser.getXxxValue()` 方法会安全处理空值

### Q4: 表头可以使用中文吗？
**A:** 
- 可以，推荐使用中文表头
- 在代码中使用相同的中文名称获取值：
  ```java
  String cityCode = ExcelParser.getStringValue(testCase, "城市代码");
  ```

## 最佳实践

1. **表头命名**
   - 使用清晰、简洁的列名
   - 避免特殊字符和空格
   - 中英文都可以，保持一致性

2. **数据准备**
   - 准备正常场景和异常场景的测试数据
   - 包含边界值测试
   - 添加备注列说明测试目的

3. **文件组织**
   - 一个 Excel 文件对应一类测试场景
   - 使用有意义的文件名，如 `maternity-leave-test-cases.xlsx`
   - 可以使用多个 Sheet，但当前只解析第一个 Sheet

4. **版本管理**
   - 测试文件也应纳入版本控制
   - 文件名包含版本号或日期，如 `test-cases-v1.0.xlsx`
